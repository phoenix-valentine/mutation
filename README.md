# Mutation: Become the Monster

A pixel-art roguelite you play in your browser. Grow a monster from mutations, eat humanity, survive four acts and six bosses.

**Play:** https://phoenix-valentine.github.io/mutation/

On a phone: open the link, then add it to your home screen (iPhone: Safari → Share → Add to Home Screen; Android: Chrome → Install app) to play full screen, offline.
